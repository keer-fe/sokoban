# 推箱子微信小游戏

原生 Canvas 2D + ES Modules，无运行时第三方依赖，不需要 npm 构建即可在微信开发者工具中编译。首页依据 `docs/主界面.html` 实现。

## 启动

- 微信：开发者工具导入项目根目录，使用已有 AppID，点击编译。
- 浏览器：Node.js 18+，执行 `npm run dev`，访问 http://127.0.0.1:8766。
- 检查：`npm run check`；行为测试：`npm test`。无需安装依赖。

浏览器预览直接复用小游戏页面和绘制代码，仅替换平台适配器。URL 可增加 `?safeTop=96&safeBottom=34` 模拟安全区域；它不替代微信模拟器和真机验收。

## 目录与扩展约定

```text
game.js                 微信入口，仅组装并启动应用
src/app.js              画布、渲染循环、生命周期、页面动作接入
src/platform/wechat.js   微信 API、触摸、胶囊和安全区域适配
src/core/viewport.js     逻辑坐标 / 屏幕坐标转换与缩放
src/ui/                 主题、绘制基础函数、插画、按钮及命中交互
src/pages/home/         首页配置、布局计算、页面组合
preview/                浏览器预览适配，不打入小游戏包
tools/                  零依赖本地开发与检查命令
tests/                  布局、交互和生命周期的 Node 测试
```

- 页面仅通过注入的动作回调调用业务，不直接访问 `wx`；后续选关、游戏页复用 `ui` 和 `core`。
- 颜色在 `ui/theme.js` 维护，文案和展示数据在 `pages/home/config.js` 维护，布局在 `layout.js` 维护。
- 插画使用本地 Canvas 路径绘制，不加载设计稿中的 React、远程 CDN 或外部图片。
- 输入与绘制共享逻辑坐标，DPR 只影响画布清晰度；应用进入后台停止动画，销毁时解绑事件。
- `createApp(platform, { start, levels })` 提供首页动作接入点；当前两个入口显示开发中提示，尚未实现游戏或选关页。
- “100 关卡 / 3 难度 / ∞ 乐趣”保留设计稿展示文案，不代表已接入关卡；接入正式关卡目录时应替换为真实数据。签到未在此次 HTML 首页设计中出现，本次不新增签到入口。
