# 箱箱向前

微信小游戏首版原型，按 `docs/sokoban-mini-game-prd.md` 实现基础可玩闭环。

## 运行方式

1. 打开微信开发者工具。
2. 选择「小游戏」并导入当前目录。
3. AppID 可先使用测试号或替换 `project.config.json` 中的 `appid`。
4. 编译后从首页点击「开始游戏」进入第 1 关。

## 已实现

- 启动加载页、首页、关卡页。
- 前 20 关运行时数据，首页仍按 PRD 显示 100 关总进度。
- Canvas 棋盘渲染、方向键移动、推箱规则、通关判断。
- 重新开始、返回首页、关卡内菜单。
- 撤销卡：新用户 3 张、每次撤销消耗 1 张。
- 每日签到：本地自然日领取 5 张撤销卡。
- 撤销卡不足弹窗和模拟广告结果：完整观看、中途退出、加载失败。
- 通关弹窗：星级、本次步数、下一关。
- 本地存档：进度、撤销卡、签到日期、音效/音乐开关、历史最高星级。

## 当前边界

- 首版使用 Canvas 几何绘制，未接入 Kenney 素材包和音频资源。
- `levels.js` 中的 `bestSteps` 是基于地图规模生成的临时门槛，后续应替换为离线求解器结果。
- 激励视频广告为开发期模拟入口，真实上线前需要替换为微信 `createRewardedVideoAd`。
- 当前开放前 20 关；补齐求解数据后可提高 `config.js` 和 `levels.js` 中的开放关卡数。
