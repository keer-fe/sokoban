# 箱不到八

Canvas 微信小游戏推箱子。现有版本使用桃色、蓝色交替的几何棋盘、连贯的凹陷通道与方块角色，包含 24 个单人关卡、方向键和滑动操作、长按连续移动、撤销、重开、提示、音效开关与本地进度保存。移动、推动、入位和通关有独立的轻量反馈。

## 构建

需要 Node.js 18+ 和 `npm`。在项目根目录运行：

```sh
npm install
npm test
npm run check:levels
WECHAT_APPID=<你的小游戏 AppID> npm run build
```

浏览器预览入口：`dist/web/index.html`（需通过本地 HTTP 服务打开）。在微信开发者工具中选择「导入项目」，项目目录选本仓库的 `dist/wechat`；`game.json`、`game.js` 和 `project.config.json` 都在其中。导入前须用实际小游戏 AppID 构建；默认的 `touristappid` 无法作为正式小游戏 AppID 导入。修改源码后重新运行构建命令，再从微信开发者工具编译。当前几何画面由 Canvas 实时绘制，构建包不再携带旧图片素材。

## 操作

- 点击方向键、按住方向键或在棋盘上滑动来移动。
- 左下角撤销，右下角显示下一步提示。
- 游戏页左上角菜单中可重开本关或切换音效。
- 通关后自动保存最佳步数并解锁下一关。

`scripts/check-levels.js` 使用求解器确认 24 关均可解。浏览器测试与求解检查不能代替微信真机的触控、性能和安全区域验收。
