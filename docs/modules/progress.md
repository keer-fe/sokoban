# 进度、存档与回放模块

## 本地存档

`ProgressStore` 保存：

- 各模式的关卡成绩、最高星级和最佳步数。
- 已开放关卡和引导状态。
- 撤销卡数量。
- 音乐、音效和震动偏好。
- 已记录的最短通关操作序列。

损坏或旧版本存档必须安全迁移或回退，不能阻止游戏启动。地图重排后按稳定关卡 ID 对应记录，不能按数组下标套用旧成绩。

## 撤销

- 只撤销成功移动。
- 撤销同时恢复角色位置、箱子位置、朝向、机关状态和步数。
- 没有历史、卡片不足或存储失败时不得产生部分状态修改。
- 重开会清空本局历史，但不会返还已经使用的卡片。

## 回放

- 只录制有效移动，撤销会移除对应操作。
- 仅用更短的有效通关记录替换已保存解法。
- 播放、单步、倒退和重播不扣卡、不保存成绩。
- 退出回放后恢复进入回放前的游戏状态。

## 当前边界

本地存档不等同于微信云存档。排行榜成绩上传不会恢复另一台设备上的棋盘、设置、撤销卡或完整关卡记录。
