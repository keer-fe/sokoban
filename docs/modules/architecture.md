# 工程架构与启动

## 运行环境

项目是原生微信小游戏：Canvas 2D + ES Modules，无运行时第三方依赖，不需要构建步骤。

启动方式：使用微信开发者工具导入项目根目录，使用项目已有 AppID 后编译。项目不提供浏览器运行模式。

## 分层

- `game.js`：微信入口，只创建微信平台适配并启动应用。
- `src/app.js`：画布、生命周期、渲染循环、页面和弹窗组装。
- `src/platform/wechat.js`：微信 API、触摸、安全区、云文件和音频适配。
- `src/pages/`：首页、选关、游戏和排行榜页面。
- `src/game/`：规则引擎、关卡目录、进度存储、控制器和死锁检测。
- `src/ui/`：共享绘制、主题、棋盘、按钮、弹窗和资源加载。
- `open-data/`：微信开放数据域中的好友榜。
- `cloudfunctions/`：世界榜和在线 PK 云函数。

页面只能通过控制器动作调用业务逻辑，不直接访问全局 `wx`。微信能力统一留在 `src/platform/` 边界。

## 生命周期

应用进入前台时恢复渲染、同步榜单和房间状态；进入后台时停止动画、输入和音频。重复启动不会叠加订阅或渲染循环。

## 本地检查

```sh
npm run check
npm test
```

这两项只证明静态检查和 Node 测试通过，不能替代微信开发者工具、体验版或真机验证。
