# 视觉与资源模块

## 规范入口

唯一设计标准为 [视觉规范 v1](../visual-spec.md)，其中包含用户确认的首页原图、色彩、材质、布局、交互、扩展位及迁移边界。资产生成计划见 [首页拆分清单](../home-assets.md)。母版已确认，代码迁移尚未完成。

## 资源分层

- `images/visual-v1/`：新视觉专用目录；`reference/` 存母版原件并排除打包，`home/` 与 `shared/` 用于后续正式素材。
- `assets/generated/`：既有游戏资源，属于待迁移资产，不再作为新首页素材存放目录。
- `assets/animation/`：人物和推箱动画。
- `assets/ui/`：本地 UI 回退资源。
- `assets/cloud-downloads/`：已下载的云端资源核对副本。
- `output/imagegen/`：生成过程、提示词和参考图，不属于运行时包。

## 运行时接入

资源生成完成不代表功能完成。每个新资源必须同时：

1. 在对应 `src/ui/` 或页面模块中声明来源。
2. 明确本地打包或云端加载方案；使用云端时核对真实 CloudBase fileID、上传结果和地址回退，不把本地文件当作已上传资源。
3. 更新 `project.config.json` 的打包策略。
4. 更新依赖资源路径的测试。
5. 在微信开发者工具和目标设备检查实际尺寸、裁切和清晰度。

`assets/generated/` 当前从本地包排除，因此仅把图片放入目录不会自动进入体验版。

## 禁止项

不再使用旧版“纯天空蓝 + 草绿 + 橙木头 + 粗黑描边 + 强塑料高光”作为新页面生成模板。`docs/主界面.html` 和旧提示词只可用于结构或历史对照。
