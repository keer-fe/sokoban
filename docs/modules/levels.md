# 模式与选关模块

## 职责

选关模块展示模式入口、关卡地图预览、锁定状态、历史星级和当前推荐关卡，并负责触摸滚动和关卡跳转。

## 模式

- 经典模式：当前主要的 100 关目录。
- 机关冒险：使用独立目录和解锁进度。
- 双人合作：保留独立模式入口和目录边界。
- 双人 PK：入口转入在线房间流程。

每个模式必须使用自己的关卡目录、解锁进度和滚动位置，不能按展示下标混用记录。

## 主要文件

- `src/pages/levels/index.js`：模式卡、关卡卡、触摸滚动与点击路由。
- `src/game/levels.js`：模式目录、编号和关卡查找。
- `src/game/maps.js`：经典关卡运行时数据。
- `src/game/progress.js`：关卡解锁和成绩读取。

## 状态语义

- 锁定：前置关卡未完成，不能进入。
- 已解锁：可以进入或重玩。
- 推荐：当前模式中建议继续的下一关。
- 星级：保存历史最高值，较差重玩不降级。

## 验证重点

- 模式切换不串关卡、不串滚动位置。
- 点击区域必须与裁切后的可见卡片一致。
- 锁图、当前关标识和星级按资源语义绘制，不能依赖数组位置猜测资源。
