# 验证与发布

## 自动化检查

```sh
npm run check
npm test
```

- `npm run check`：检查 JavaScript 语法和 JSON 配置。
- `npm test`：验证规则、存档、布局、绘制调用、榜单、回放和云函数数据处理。
- `git diff --check`：检查补丁中的空白错误。

针对单项测试使用：

```sh
node --test --test-name-pattern='关键字' tests/example.test.js
```

## 微信开发者工具

至少检查：

- 编译无报错，主域和开放数据域控制台无异常。
- 云图片、字体、音频和开放数据域资源能够加载。
- 胶囊、安全区、触摸坐标和不同屏幕尺寸正确。
- CloudBase 环境、云函数和数据库权限与当前 AppID 一致。

## 体验版与真机

需要单独验证：

- 体验版资源是否被正确打包或从云端下载。
- 好友关系、头像昵称、隐私声明和排行榜同步。
- 两台设备的 PK 创建、加入、完成和结算。
- 切前后台、弱网、断网恢复和音频行为。

## 结论用语

- “测试通过”：仅指 Node 自动化测试。
- “开发者工具通过”：必须实际在微信开发者工具验证。
- “体验版通过”：必须上传并运行对应体验版本。
- “真机通过”：必须记录设备和验证路径。

四类结论不能互相替代。
