# 首页模块

## 职责

首页负责游戏入口、选关入口、排行榜入口、设置入口和微信原生游戏圈按钮布局。

## 主要文件

- `src/pages/home/index.js`：页面绘制和按钮动作。
- `src/pages/home/layout.js`：安全区和不同屏幕尺寸下的布局。
- `src/pages/home/config.js`：文案和展示数据。
- `src/pages/home/push-animation.js`：首页人物推箱动画。
- `src/ui/home-icons.js`：首页背景、标题和按钮资源加载。
- `src/ui/home-font.js`：艺术字体加载与回退。

## 行为

- “开始游戏”进入当前可继续的关卡流程。
- “关卡选择”进入模式与关卡列表。
- 排行榜打开好友榜/世界榜弹层。
- 设置项由控制器保存并在后续启动中恢复。
- 游戏圈按钮由微信原生 API 创建，只在首页可交互状态显示。

## 视觉约束

首页使用项目当前的明亮 2.5D 手绘卡通资源。`docs/主界面.html` 只保留为早期结构参考，不应继续作为新页面的视觉生成基线。

## 验证重点

- 顶部安全区和微信胶囊区域不能遮挡按钮。
- 短屏、全面屏和横屏下按钮不得重叠。
- 云资源加载失败时保留可操作的 Canvas 回退。
