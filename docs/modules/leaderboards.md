# 排行榜模块

排行榜分为好友榜和世界榜，两者的数据来源、权限和验证方式不同。

## 好友榜

好友榜使用微信开放数据域和托管数据：

- `open-data/index.js`：开放数据域入口。
- `open-data/model.js`：数据校验、排名和同步队列。
- `open-data/context.js`：调用微信关系链接口并绘制共享画布。
- `src/platform/friend-board.js`：主域与开放数据域消息桥。

真实好友关系只能在开放数据域读取。主域只接收共享画布，不接收好友名单。进度相同时采用并列名次；读取失败时不以较低本地值覆盖云端值。

## 世界榜

世界榜使用 CloudBase：

- `src/platform/world-leaderboard.js`：客户端提交和查询。
- `cloudfunctions/submitLeaderboard/`：按 OPENID 提交版本化成绩。
- `cloudfunctions/getWorldLeaderboard/`：返回清洗后的排名。
- `leaderboard_players`：云数据库集合。

玩家头像和昵称通过首次启动用户操作获取并缓存；进入世界榜时不重复请求授权。

## 真机联调

1. 使用真实 AppID 在微信开发者工具重新编译，确认主域和开放数据域无错误。
2. 使用两个互为好友且有体验权限的微信账号在两台设备打开同一版本。
3. 分别通关不同数量的关卡，刷新好友榜并检查排序、并列和同步。
4. 断网通关后恢复网络，回到前台或刷新，确认补传。
5. 世界榜检查头像、昵称、本人标记、总星数和排名。

## 验证边界

Node 测试只能覆盖排序、消息、错误和绘制逻辑。微信好友关系、隐私声明、真实头像、云端写入和跨设备可见性必须在开发者工具、体验版或真机验证。
