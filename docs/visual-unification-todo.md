## 推荐执行顺序

1. 已完成：全部现有设计稿确认、设计文档收口与全局素材清单。
2. 按素材清单制作共用组件与首页分层；首先制作首页纯背景，复核构图后扩展。
3. 接入共用组件、首页和加载页，再推进模式/选关、排行榜与弹窗。
4. 制作并接入棋盘、机关、回放和联机专用素材；对应功能规则及协议另行落实。
5. 每批完成静态检查与开发者工具验证，再进行体验版和真机验收；联机流程使用两台设备。
6. 确认引用归零与目标构建通过后清理旧资源，记录最终版本和验证边界。

收到新的视觉反馈时修正对应组件或母版并记录变更，不将素材完成或设计确认混同于运行时验收。
