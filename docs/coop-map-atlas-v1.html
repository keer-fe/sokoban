CO-OP SOKOBAN / 第一章原型

两个人，一起把箱子送回家

6 张可解性验证地图。前 3 关学习守门与运箱，后 3 关加入岗位交换和接应。这是独立设计原型，尚未接入游戏，也未经过双人试玩。

🔵 1 / 🟠 2：各自控制的角色▣：箱子◎：目标a → A、b → B：压力板控制同字母门

规则：每次一个角色移动一格；不能重叠、拉箱或连续推多个箱子。人和箱子都可压板。离板关门，但门格内已有的人或箱子可以退出；能否进入门按本步开始时的板状态判断。所有箱子到目标即通关，无需角色到达出口。

验证口径：步数是两人移动总和，包含走路与推箱。固定任意一个角色在出生点，另一角色均无法单独完成。此检查不等于证明每个机关都无法绕过；动作分配、等待时间与趣味性仍需试玩。
