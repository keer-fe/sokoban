# 《箱箱向前》微信小游戏 PRD（第一版）

版本：v0.2  
日期：2026-10-09  
产品形态：微信小游戏  
游戏类型：单人、竖屏、益智、推箱子  
第一版关键词：100 关地图、方向键操作、撤销卡、每日签到、激励视频广告、星级结算

## 1. 产品定义

### 1.1 产品名称

推荐名称：**箱箱向前**

命名理由：

- “箱箱”直接对应推箱子的核心物件。
- “向前”表达闯关推进感。
- 名称轻量、口语化，适合微信小游戏。
- 不绑定具体角色和美术风格，后续换皮或扩展主题时仍可沿用。

备选名称：

- **推箱小队**：更偏团队感，适合后续增加角色。
- **箱子别挡路**：更轻松，但略口语。
- **一步推箱**：强调益智和步数，但辨识度稍弱。
- **小小推箱王**：小游戏感强，但偏传统。

第一版文档后续统一使用推荐名称「箱箱向前」。

### 1.2 产品一句话介绍

《箱箱向前》是一款轻量推箱子微信小游戏，玩家通过方向键移动角色，把所有箱子推到目标点，挑战更少步数通关。

### 1.3 产品详细介绍

《箱箱向前》面向碎片时间游玩的休闲益智用户。游戏采用经典推箱子规则：玩家每次移动一格，遇到箱子时可将箱子向前推动一格，目标是把所有箱子推到对应目标点。第一版不加入复杂养成、排行榜、皮肤、社交求助等系统，重点打磨关卡可玩性、操作手感、撤销体验和通关反馈。

玩家在关卡中看不到实时步数，减少压力；通关后展示星级和本次使用步数，引导玩家感知自己的表现。走错时可以使用撤销卡回退一步。撤销卡通过新手赠送、每日签到和激励视频广告获得。

### 1.4 产品定位

- 轻量休闲益智小游戏。
- 低学习成本、低操作负担。
- 以关卡推进和步数挑战为主要驱动力。
- 第一版优先做可玩闭环，不追求复杂商业化。

### 1.5 第一版产品目标

- 用户打开小游戏后，可以在 10 秒内进入第一局。
- 前 20 关至少形成完整可玩体验。
- 玩家可通过撤销卡修正错误，降低卡关挫败感。
- 玩家每天有一个轻量回访理由：签到领取撤销卡。
- 通过撤销卡不足时的激励视频广告建立基础变现入口。

### 1.6 第一版成功标准

功能成功：

- 首页、关卡、通关、下一关、返回首页流程完整。
- 方向键移动和推箱规则稳定。
- 重新开始、撤销、签到、广告奖励、本地存档可用。
- 前 20 关均可通关，并有星级门槛。

体验成功：

- 新玩家不看说明也能理解如何开始。
- 棋盘在主流手机竖屏下完整显示。
- 方向键点击区域足够大，不容易误触。
- 撤销卡数量和撤销反馈清楚。

技术成功：

- 关卡数据可配置。
- 最优步数离线生成。
- 游戏运行时不实时求解关卡。
- 存档结构可支持后续扩展选关、补星、好友求助。

## 2. 用户与场景

### 2.1 目标用户

核心用户：

- 喜欢益智小游戏的微信用户。
- 有推箱子、华容道、数独、消除等轻度益智游戏经验的用户。
- 希望在等车、休息、睡前玩几分钟小游戏的用户。

扩展用户：

- 想挑战更少步数通关的玩家。
- 喜欢连续闯关、有轻度收集目标的玩家。
- 后续可能通过好友求助、分享解法进入的社交用户。

### 2.2 用户需求

基础需求：

- 快速开始一关。
- 清楚知道当前要做什么。
- 操作稳定、反馈明确。
- 走错时可以恢复。
- 通关后有成就反馈。

进阶需求：

- 想知道自己走得好不好。
- 想继续挑战下一关。
- 卡住时不想直接放弃。
- 以后希望能回头补星或请朋友帮忙。

### 2.3 典型用户路径

新用户首次进入：

1. 打开小游戏。
2. 看到首页和「开始游戏」。
3. 系统初始化存档，赠送 3 张撤销卡。
4. 点击「开始游戏」进入第 1 关。
5. 使用方向键移动角色。
6. 通关后看到星级和步数。
7. 点击「下一关」进入第 2 关。

老用户再次进入：

1. 打开小游戏。
2. 首页显示当前进度，例如「第 6 / 100 关」。
3. 右侧签到图标提示今日可领取。
4. 点击签到，领取 5 张撤销卡。
5. 点击「开始游戏」进入当前未通关关卡。

卡关用户路径：

1. 玩家在关卡中走错。
2. 点击「撤销」。
3. 如果有撤销卡，回退一步。
4. 如果撤销卡为 0，弹出广告奖励弹窗。
5. 玩家看完广告，获得 3 张撤销卡。
6. 继续撤销和游玩。

## 4. 产品图标设计

### 4.1 图标目标

图标需要在微信小游戏入口里快速表达「推箱子」「益智」「轻松」。图标不需要复杂背景，也不依赖小字说明。

### 4.2 推荐图标方案

图标名称：**小角色推箱**

画面构成：

- 主体：一个简化卡通角色侧身推一个木箱。
- 箱子：使用明显的木箱形态，带十字木条或边框。
- 目标点：箱子前方或下方有一个浅色目标格。
- 背景：明亮纯色或轻微棋盘格背景。
- 风格：圆润、清晰、偏休闲，不做复杂细节。

构图：

- 角色占左侧 35%。
- 箱子占中间 45%。
- 目标点或箭头占右下角 20%。
- 图标边缘留 8% 安全边距。

颜色建议：

- 背景：浅蓝、浅绿或暖黄色。
- 箱子：橙棕色。
- 目标点：绿色或金色。
- 角色：使用素材包角色或简单原创角色。

### 4.3 图标尺寸

设计源文件建议：

- 1024 × 1024。
- PNG。
- 保留透明或纯色背景版本。

导出尺寸：

- 1024 × 1024：应用主图标。
- 512 × 512：备用。
- 256 × 256：后台预览。
- 128 × 128：小尺寸检查。

### 4.4 图标验收标准

- 缩小到 64 × 64 时仍能看出是推箱子。
- 不使用细小文字。
- 不使用复杂场景截图。
- 不直接使用参考图中的角色或品牌元素。
- 与游戏内棋盘素材风格不冲突。

第一版使用 Kenney Sokoban 素材包。

素材包地址：

用途：

- 墙。
- 地板。
- 目标点。
- 箱子。
- 已归位箱子。
- 角色。
- 基础棋盘元素。

### 5.2 布局参考

用户提供的参考图只作为布局参考。

可参考：

- 竖屏结构。
- 首页中央主视觉。
- 底部大按钮。
- 侧边悬浮入口。
- 顶部避开微信胶囊按钮。
- 游戏主区域突出。
- 操作按钮使用大面积点击区域。

不参考：

- 具体角色。
- 具体品牌。
- 具体文案。
- 具体玩法。
- 具体商业入口数量。

### 5.3 UI 风格

方向：

- 休闲。
- 卡通。
- 清晰。
- 轻量。

原则：

- 棋盘优先清楚，不被装饰干扰。
- 按钮优先大且好点。
- 文案短，避免说明堆叠。
- 第一版不做复杂动画，保证性能。

### 5.4 关键视觉元素

棋盘：

- 地板、墙、箱子、目标点、角色必须区分明显。
- 箱子在目标点上需要有清晰状态变化。
- 目标点不能被箱子完全遮挡到无法理解。

按钮：

- 开始游戏按钮最大。
- 方向键按钮必须稳定、等宽、等高。
- 撤销按钮和方向键区分明确。
- 弹窗主按钮和取消按钮层级清楚。

反馈：

- 有效移动：角色移动动画。
- 推箱：箱子移动动画。
- 无效移动：轻微抖动或提示音。
- 撤销成功：回退动画或瞬时回退。
- 通关：星级动画。

规则：

### 6.3 首页

页面目标：

- 让用户快速开始。
- 展示当前进度。
- 提供签到入口。
- 提供基础设置入口。

页面布局：

```text
┌────────────────────┐
│ 设置            胶囊区 │
│                    │
│      游戏标题       │
│      主视觉图       │
│                    │
│      第 X / 100 关  │
│                    │
│     [ 开始游戏 ]    │
│                    │
│              签到悬浮 │

```

元素说明：

- 设置按钮：左上角齿轮。
- 微信胶囊区域：右上角预留安全区，不放重要按钮。
- 游戏标题：使用产品名称「箱箱向前」。
- 主视觉：角色和箱子组合。
- 当前进度：显示玩家当前未通关关卡。
- 开始游戏：主行动按钮。
- 每日签到：右侧悬浮图标。

交互：

- 点击「开始游戏」进入当前未通关关卡。
- 新玩家进入第 1 关。
- 点击「每日签到」打开签到弹窗。
- 点击设置按钮打开设置弹层。

首页文案建议：

- 标题：`箱箱向前`
- 主按钮：`开始游戏`
- 进度：`第 {currentLevel} / 100 关`

### 6.4 关卡页

页面目标：

- 让玩家完整看到棋盘。
- 提供稳定方向键操作。
- 提供撤销和菜单能力。

页面布局：

```text
┌────────────────────┐
│ 第 X 关   撤销卡 xN  菜单 │
│                    │
│                    │
│       棋盘区域       │
│   完整居中自动缩放    │
│                    │
│                    │
│          ↑         │
│   撤销   ← ↓ →      │
└────────────────────┘
```

顶部区域：

- 左侧：关卡号。
- 中间或右侧：撤销卡数量。
- 右侧：菜单按钮。
- 需要避开微信胶囊区域。

棋盘区域：

- 居中。
- 自动缩放。
- 保证完整显示。
- 不拖动。
- 不缩放。

底部操作区：

- 方向键固定在底部中间。
- 撤销按钮放方向键左侧。
- 撤销按钮常驻。
- 撤销按钮可显示卡数量角标，或顶部统一显示数量。

### 6.5 关卡内菜单弹层

触发：

- 点击关卡页菜单按钮。

内容：

- 继续游戏。
- 重新开始。
- 返回首页。
- 音乐开关。
- 音效开关。

规则：

- 弹层出现时暂停棋盘输入。
- 不影响当前局面。
- 点击遮罩或继续游戏关闭弹层。
- 重新开始不二次确认。

### 6.6 每日签到弹窗

入口：

- 首页右侧悬浮签到图标。

未领取状态：

- 签到图标显示红点或轻微动效。
- 弹窗展示今日奖励。

弹窗内容：

- 标题：`每日签到`
- 奖励：`撤销卡 x5`
- 主按钮：`领取`
- 次按钮：`稍后`

领取后：

- 撤销卡数量 +5。
- 今日签到状态变为已领取。
- 图标红点消失。
- 可展示轻提示：`已领取撤销卡 x5`

已领取状态：

- 点击签到图标可展示：`今日已领取`

### 6.7 撤销卡不足弹窗

触发：

- 玩家点击撤销。
- 当前撤销卡数量为 0。

弹窗内容：

- 标题：`撤销卡不足`
- 说明：`观看广告可获得 3 张撤销卡`
- 主按钮：`观看广告`
- 次按钮：`取消`

交互：

- 点击观看广告，调起激励视频。
- 完整观看后发放 3 张撤销卡。
- 中途退出或失败不发放。
- 发放后关闭弹窗，玩家可再次点击撤销。

### 6.8 通关弹窗

触发：

- 所有箱子在目标点上。

展示内容：

- 标题：`通关成功`
- 星级。
- 本次使用步数。
- 主按钮：`下一关`
- 次按钮：`返回首页`

不展示：

- 三星门槛。
- 二星门槛。
- 最优步数。
- 排名。

第 100 关通关：

- 标题：`全部通关`
- 文案：`已完成当前全部关卡，更多地图和玩法正在开发中`
- 按钮：`返回首页`

## 7. 功能设计

### 7.1 开始游戏

入口：

- 首页「开始游戏」。

规则：

- 如果没有存档，初始化存档并进入第 1 关。
- 如果存在存档，进入 `currentLevelId` 对应关卡。
- 如果 `currentLevelId > 100`，显示全部完成弹窗或首页完成状态。

### 7.2 推箱子玩法

基础元素：

- 墙：不可进入。
- 地板：可进入。
- 目标点：可进入。
- 箱子：可推动。
- 角色：玩家控制对象。
- 箱子在目标点：仍为箱子，但显示已归位状态。

移动规则：

- 玩家每次只能朝一个方向移动一格。
- 目标格是地板或目标点时，角色移动过去。
- 目标格是箱子时，检查箱子后一格。
- 箱子后一格可进入时，箱子被推动一格，角色移动到箱子原位置。
- 箱子后一格是墙、边界或另一个箱子时，移动无效。

通关规则：

- 所有箱子都在目标点上时通关。
- 箱子数量必须等于目标点数量。

无效操作：

- 不计步。
- 不写入撤销历史。
- 可播放轻微反馈。

### 7.3 重新开始

入口：

- 关卡内菜单。

规则：

- 直接重开。
- 不弹确认。
- 恢复当前关初始状态。
- 当前步数清零。
- 当前撤销历史清空。
- 不消耗撤销卡。
- 不影响已获得星级。
- 不影响已解锁进度。

### 7.4 撤销

入口：

- 关卡页底部撤销按钮。

可撤销内容：

- 上一次有效移动。
- 包括普通移动。
- 包括推箱移动。

不可撤销内容：

- 无效移动。
- 打开菜单。
- 关闭菜单。
- 签到。
- 看广告。
- 重新开始。

消耗规则：

- 每撤销一步消耗 1 张撤销卡。
- 撤销卡为 0 时不能直接撤销。
- 撤销卡不足时弹出广告引导弹窗。

状态变化：

- 回退角色位置。
- 回退箱子位置。
- 本局步数 -1。
- 撤销卡 -1。
- 撤销历史出栈。

边界：

- 没有历史但有撤销卡时，点击撤销可提示 `暂无可撤销步骤`，不消耗卡。
- 有历史但没有撤销卡时，弹广告引导。

### 7.5 每日签到

入口：

- 首页右侧悬浮图标。

奖励：

- 每日领取 5 张撤销卡。

日期规则：

- 按本地自然日判断。
- 存储上次领取日期。
- 同一天只能领取一次。
- 第二天可重新领取。

第一版不做：

- 连续签到。
- 补签。
- 翻倍领取。
- 看广告加倍。

### 7.6 激励视频广告

触发：

- 撤销卡不足时点击撤销。

奖励：

- 完整观看获得 3 张撤销卡。

失败处理：

- 广告加载失败：提示 `广告暂时不可用，请稍后再试`。
- 用户中途关闭：提示 `完整观看后才能获得奖励`。
- 发奖失败：不增加撤销卡，并记录错误。

开发期：

- 可用模拟广告代替真实广告。
- 模拟广告应覆盖成功、失败、中途退出三种状态。

### 7.7 星级评分

计步：

- 有效移动计 1 步。
- 推箱成功计 1 步。
- 无效操作不计步。
- 撤销回退步数。

显示：

- 游戏中不展示步数。
- 通关弹窗展示本次使用步数。

星级：

- 3 星：步数 ≤ `ceil(bestSteps × 1.2)`。
- 2 星：步数 ≤ `ceil(bestSteps × 1.5)`。
- 1 星：通关即可。

数据：

- `bestSteps` 来自离线求解器。
- 第一版先跑前 20 关。
- 游戏运行时读取预生成配置。

### 7.8 关卡推进

规则：

- 第一版不做选关。
- 玩家只能玩当前未通关关卡。
- 通关后解锁下一关。
- 通关后点击「下一关」进入下一关。
- 返回首页后，再点开始游戏进入当前未通关关卡。

第 100 关：

- 通关后不进入第 101 关。
- 展示更多地图和玩法开发中的提示。

## 15. 风险与注意事项

### 15.1 关卡难度风险

当前地图集中后期关卡箱子数量较多，可能不适合第一版直接开放 100 关。

应对：

- 先做前 20 关。
- 先跑最优步数。
- 根据求解结果和试玩反馈决定开放数量。

### 15.2 求解器耗时风险

大地图、多箱关卡可能求解时间很长。

应对：

- 第一阶段只跑前 20 关。
- 对求解失败或耗时过长的关卡先后移。
- 游戏运行时不实时求解。

### 15.3 操作误触风险

方向键过小会影响体验。

应对：

- 方向键区域固定在底部。
- 按钮点击区域大于视觉图形。
- 移动动画期间限制连续输入。

### 15.4 棋盘过小风险

大地图一屏显示可能导致格子过小。

应对：

- 第一版优先选择尺寸较小的前 20 关。
- 如果某些关过大，延后开放。
- 后续再考虑棋盘拖动或缩放。
