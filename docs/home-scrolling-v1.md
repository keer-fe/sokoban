# 首页连续推箱重构

2026-10-27。静态母版继续约束 Logo、按钮、左右入口、阳光花园色彩与材质。中央固定棋盘已由循环花园道路替代。环境分层向左移动，人物和木箱保持居中，目标格随道路偶尔经过。

## 运行时结构

- `src/pages/home/scrolling-scene.js` 按经过时间计算远景、草地、道路和近景的相位。横向图层每隔一幅镜像，接边使用同一列像素，避免出现硬接缝。
- 首版 12 帧图集各帧的上半身和前脚并不连续，直接切帧会跳动。当前从同一图集的稳定姿势取上半身和双脚，以手掌接触点为轴作极小幅连续倾斜，双脚按连续的支撑与摆动轨迹交替前进；支撑阶段脚的屏幕位移与道路速度相匹配。图集仍保留在资源中，后续若有真正连续的人工逐帧素材可替换。木箱作为一整张图片等比绘制，接触阴影独立绘制。
- 目标底格随道路移动，径向光和光圈独立按时间脉动。
- `src/ui/home-visual-v1.js` 加载本地 `visualHome` 素材。整组资源加载完成后启用新画面；任一资源失败时首页继续使用旧的可操作画面。

## 素材

生产资源均在 `images/visual-v1/home/`，由已确认母版和旧角色稿引导生成，再在浏览器运行画面中复核。当前使用 `garden-panorama-v1.png` 远景、`garden-road-v2.png` 透明石砖道路、`garden-foreground-v1.png` 透明近景花草、`hero-walk-push-v1.png` 人物图集、`crate-left-face-v3.png` 独立木箱及 `goal-base-v2.png` 无光效目标底格。生成提示词要求保持母版的左上受光、圆润砂岩、透视一致的道路和木箱、角色黄色探险帽与蓝色服装、透明分层及连续步态。生成结果仍需以实际运行预览验收；生成过程不等同于逐帧人工绘制。

2026-10-28 根据局部截图反馈，正式运行改用 `crate-left-face-v3.png` 和 `garden-road-v2.png`。两张图均通过内置 ImageGen 编辑模式生成，保留旧版作对照。箱子提示词强调人物从左向右推时可见左侧受力面、顶部和正面透视一致、左上光照、真实透明背景；道路提示词强调与远景草地同色系、花草稀疏、上下边缘自然过渡、石砖连续。运行时另沿道路下缘渐退透明度，并减轻底部花草层；人物上半身的遮挡边界沿背带裤下摆绘制，避免横向裁切线。

旧 `diorama-base-v5.png`、`hero-effort-v7.png`、`background-v1.png`、`crate-v1.png`、`crate-v2.png` 和 `garden-road-v1.png` 已从当前打包项排除；仍供其他页面使用的资源未清理。
