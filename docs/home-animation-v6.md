# 首页原地轻动画 v6（历史）

> 人物和箱子已由 [v7](home-animation-v7.md) 替代；环境和目标轻动画继续使用。

2026-10-23，按用户最新要求替代 v5 推动一格循环。

## 当前效果

- 人物原地努力推箱：3.2 秒平滑发力循环，双脚固定，单一人物姿势的上身绕手掌接触点做最多约 1.6° 小角度旋转。没有整个人平移、拉伸、换脸或淡出。
- 额头附近三颗蓝色汗滴错峰下落，透明度在循环两端归零；汗滴与人物独立绘制。
- 目标格位置固定，2.4 秒暖黄色呼吸光、低透明扩散圈和三颗上浮星芒。
- 两只小蝴蝶在 Logo 旁和场景侧边缓慢飞动、扇翅；六颗低透明浮光缓慢漂动；开始按钮约 0.6% 幅度呼吸。各层不同周期，避免整页同步摆动。
- 点击场景会增强 1.2 秒的发力与目标光效，不重置时间相位；连续点击节流。按钮按压、拖出取消、多指隔离及至少 44 屏幕像素的工具触摸区域保持有效。

## 箱子与地面

当前箱子不需要位移，因此直接采用 `images/visual-v1/home/diorama-base-v3.png` 内与原棋盘配套的静态箱子。其边缘方向、材质、光照与棋盘一致，避免叠加 v5 中透视不同的独立箱子。该图为 860×660 RGBA，场景绘制区域仍为母版坐标 `(45,435,860,660)`。

人物起点 `(288,622)`，手掌锚点 `(450,765)`。腿部裁切区域不加变换；上身小角度绕手掌转动，腰部重叠 4 个源像素以遮盖接缝。人物仍是轻量刚体动画，不是完整骨骼蒙皮。

此版本复用已查看的现有素材，没有生成新的位图。`home-visual-v1.js` 已引用 v3 棋盘并移除独立箱子的加载；打包配置恢复 v3 棋盘，排除闲置 v5 棋盘和独立箱子。旧文件保留作历史参考。
