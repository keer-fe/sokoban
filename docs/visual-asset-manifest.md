## 生产约定

- 以下路径均相对 `images/visual-v1/`；目录随首批真实素材创建。除明确已交付者外，名称为拟定交付名。
- 表内“一族”可拆成多个文件；花括号表示需展开的状态或方向，不是实际文件名。具体帧数、图集排布在制作时记录，不预设已交付数量。
- 背景优先不透明 JPG；H01 保留已确认无损 PNG，压缩导出在接入时复核。独立图形用带真实 alpha 的 PNG。复杂艺术图生成或重绘；进度、文字、路径及简单状态通过 Canvas 绘制。
- 尺寸是制作起点，不是验收值：全屏背景约 1080×1920；大插画约 1024×1024；面板约 800×1000；按钮约 600×200；图标约 192×192；棋盘元素约 256×256。按实际可见边界、DPR 和包体积调整，禁止拉伸变形。
- 面板和按钮优先九宫格缩放，制作时登记不可拉伸边距。若纹理或造型不适合九宫格，则独立交付尺寸变体。
- 共用资产只保留一个来源。首页装饰按钮、首页微缩场景与棋盘素材不得因名称相似直接混用；需核对透视、装饰和锚点。
- 默认、按下、禁用、加载均须可表达：按下位移和阴影、禁用颜色与点击阻断、加载动画优先由组件实现；只有轮廓或图案改变才另出图。
- 加载方案待首次接入时确定；每件素材须登记本地打包或真实云端 fileID。参考图继续排除发布包，不提前填写云端地址。
