# 微信好友闯关榜

## 已实现

- 首页右上角「好友榜」入口，头像、昵称、已通关关卡、每页 6 人、刷新和翻页。
- 按最高连续通关关卡降序排列，进度相同采用并列名次（1、1、3）。
- 游戏启动、回到前台、通关保存成功、打开或刷新榜单时同步已有本地进度。
- 先读取微信托管数据再取较大值写回；读取失败不会写入。写入串行执行，失败后最多自动重试两次，后台暂停重试；下次前台或刷新继续尝试。
- 未上传数据的好友不显示。头像失败用昵称首字代替；空榜、加载失败、待同步分别展示。
- 真实好友列表只在开放数据域内读取、排序和绘制，主域只接收共享画布，不接收好友名单。

## 代码位置

| 文件 | 职责 |
| --- | --- |
| `game.json` | 配置 `openDataContext: open-data` |
| `open-data/index.js` | 微信开放数据域入口及消息订阅 |
| `open-data/model.js` | 数据校验、排名、串行进度同步 |
| `open-data/context.js` | 微信托管接口调用、超时重试、共享画布绘制 |
| `src/platform/friend-board.js` | 主域消息与共享画布适配 |
| `src/pages/friends/index.js` | 好友榜页面及翻页、刷新按钮 |
| `preview/friends.js` | 浏览器专用模拟数据，不打入小游戏包 |

不需要创建云数据库集合、部署云函数或填写 CloudBase 环境 ID。需要使用当前小游戏真实 AppID，在微信环境调用关系链接口。

托管 Key：`sokoban.selfboot100.completed.v1`。值：`{"completed":12}`。范围 0–100。地图内容或顺序改变时应更换 Key，避免混排。

## 自行联调步骤

1. 微信开发者工具导入当前目录，确认 AppID，重新编译。检查主域与开放数据域控制台是否报错。
2. 进入首页「好友榜」，观察自己的最高进度和同步状态。新玩家显示 0 关；已有本地存档按连续通关进度上传。
3. 准备两个互为微信好友的账号，均有当前开发版/体验版访问权限，分别在真机打开同一 AppID 的游戏。
4. A 通关第 1 关，B 通关第 2 关。等待上传后刷新榜单，应展示 B 高于 A。进度更新可能有平台可见延迟。
5. A 也通关第 2 关，双方刷新，应显示相同名次。重玩旧关不会降低已上传进度。
6. 断网通关：游戏应正常继续，本地记录保存；好友榜显示加载失败或待同步。恢复网络后回到前台或点击刷新，应补传。
7. 换一台本地进度较低的设备，同一微信账号打开游戏，榜单应保留云端高进度。这个功能不恢复本地棋盘、最佳步数、撤销卡或关卡解锁存档。
8. 返回首页后重新进入，检查刷新、上一页、下一页。真实好友不足 7 人时，可先用浏览器模拟数据验证分页。

浏览器运行 `npm run dev`，访问：

- `http://127.0.0.1:8766/`：显示需在微信查看的提示，不伪造好友。
- `http://127.0.0.1:8766/?friends=demo`：明确标注的 14 人模拟榜单。
- `?friends=empty`：空榜；`?friends=error`：读取好友失败；`?friends=offline`：进度同步和好友读取均失败。
- 可以追加 `&safeTop=91&safeBottom=34` 检查安全区。

## 验证边界

如果返回 `please go to mp to announce your privacy usage`，需登录对应小游戏 AppID 的微信公众平台，找到「用户隐私保护指引」配置，按界面要求声明好友排行榜实际使用的信息及用途。用途可填写“用于展示同玩好友的头像、昵称及闯关进度，生成好友闯关排行榜”。以后台实际列出的接口和信息类型为准，保存并完成后台要求的发布/生效步骤后重新编译或预览。此错误不是网络故障，也不是缺少云数据库，代码不会对它自动重试。

共享画布的物理尺寸由主域设置，开放数据域只按传入的逻辑尺寸与 DPR 绘制，避免真机字体放大和内容裁切。

已完成代码/配置检查、Node 测试以及浏览器模拟榜单与分页检查。微信真实好友关系、头像、云端写入和双账号同步尚未验证，由用户在开发者工具及真机完成。后续不通过 computer-use 代替用户验证。

本版为轻量好友进度展示，客户端上传数据，不做云端防作弊。先读后写可以避免普通单设备切换时覆盖高进度，但托管 KV 不提供本实现所需的跨设备原子取最大值；两台设备同时写入的极端竞态不保证严格单调。以后有奖励或 PK 需求再接服务端校验与原子更新。

参考：[微信关系链文档](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/open-data.html)、[Cocos 官方开放数据域说明](https://docs.cocos.com/creator/2.4/manual/zh/publish/publish-wechatgame-sub-domain.html)。本次微信官方网页未能直接读取，接口兼容性以当前开发者工具和真机结果为准。
