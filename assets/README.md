# 游戏素材

`source/sokoban.svg` 是用户提供的原始图集，来源为其腾讯云存储中的 `/images/vector/sokoban_vector.svg`。不保存临时签名到运行时代码。

`sokoban.png` 从原图按 3 倍分辨率无损导出，仅包含墙、地板、木箱、完成箱、目标点和人物六个区域，每格 192 × 192。由 `src/ui/art.js` 集中管理并在棋盘、首页、引导等处复用。源 SVG 不打入小游戏包；游戏使用本地 PNG，无远程请求和运行时 SVG 解码依赖。图集未加载或加载失败时使用原 Canvas 绘制兜底。

重新生成：`node tools/build-art.cjs [sharp 模块路径]`。Sharp 仅用于开发时转换，不是游戏运行依赖。裁切坐标基于原图的 952 × 582 坐标系，维护在转换脚本中。

目标格采用原图 `(74, 222)` 的浅色四角定位框＋内部小木箱，人物采用 `(0, 370)` 的描边版本。图集额外包含 `(0, 222)` 的独立四角框：棋盘中未完成的目标格每 1.6 秒柔和闪烁一次，仅改变框的透明度，内部小箱子保持常亮；箱子到位后显示绿色完成箱。

人物四向均使用描边素材：下 `(0, 370)`、上 `(222, 370)`、左 `(222, 518)`、右 `(0, 518)`。成功移动或推箱后改变朝向，撤销恢复上一步朝向，重开默认朝下。
