# 地图素材 V2

## 文件

- `character-walk-4dir-3frame.png`：人物行走，4 列 × 3 行。列顺序为下、上、左、右；行顺序为行走循环帧。
- `character-push-4dir-3frame.png`：人物推箱，4 列 × 3 行。列顺序为下、上、左、右；行顺序为推动循环帧。手套、袖口、掌面与双手接触姿势参考首页加载动画重新绘制。
- `map-tiles-4x4.png`：地图元素，4 列 × 4 行。
- `board-background-seamless.png`：棋盘外部及空地背景纹理。

## 地图元素顺序

按从左到右、从上到下排列：

1. 普通箱子
2. 箱子到达目标
3. 目标位置
4. 地板
5. 苔藓石墙
6. 普通石墙
7. 裂纹石墙
8. 转角石墙
9. 未触发压力板
10. 已触发压力板
11. 关闭的门
12. 打开的门
13. 碎石装饰
14. 草丛装饰
15. 人物阴影
16. 箱子阴影

人物使用与现有首页、图标和游戏内角色一致的绿色帽子、绿色上衣和红色背带裤造型。全部地图元素采用统一的正交 2D 方格视角，不使用等距透视或 3D 展示角度。

角色与地图元素图片包含透明通道；背景图片为不透明纹理。当前文件保留生成原始分辨率，接入运行时前可按目标格子尺寸统一裁切、缩放和压缩。
