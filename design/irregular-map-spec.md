# 不规则地图验证稿

本稿先验证地图形状和可读性，不作为最终材质或角色定稿。示例关卡数据见 [irregular-map-level.json](./irregular-map-level.json)，已由项目求解器验证可解。

## 地图规则

- 每个逻辑格只有四种基础状态：空缺（`~`）、墙（`#`）、可走地面（空格）、目标（`.`）。箱子和玩家在其上叠加。
- 空缺格不绘制地块，也不可通行。由空缺格形成外轮廓和凹口；墙在有效地块上形成更高一层。
- 地面、外边缘、外角、内角按四邻格关系选择素材，采用同一视角、同一光源和同一格宽。角色、箱子、目标拥有独立透明素材及固定落地锚点。
- 不规则地图缩放时先按逻辑包围盒计算格宽，再整体居中，周围留足方向键和顶部信息空间。

## 验收要点

1. 玩家不看教程也能分清空缺格、墙、可走格和目标。
2. 地图轮廓可以变化，但每个关卡仍由同一套地块及边角拼接，不画独占的大底图。
3. 检查凹角、窄通道、相邻墙、箱子贴墙时的接缝、遮挡与点击区域。
4. 至少用一个 6×6 早期关和一个 11×11 不规则关在真实手机尺寸上预览。
